# Dominic Empire OS v3.2

An opinionated, terminal-first operations and network telemetry suite built in Python and Windows PowerShell.

## Core Modules

- **`empire.py`**: Central CLI orchestrator managing sub-process execution and persistent vault storage.
- **`empire_log.py`**: Real-time biological telemetry tracker with conditional logic gates calculating daily allocations and nicotine abstinence streaks.
- **`war_chest.py`**: Financial projection engine tracking emergency capital growth toward a $1,000 baseline with terminal progress visualization.
- **`streaks.py`**: Operational streak vault monitoring chemical sobriety, physical uptime, and habit automation.
- **`vault_stats.py`**: Persistent disk parser that audits and verifies historical telemetry logs.

## CCNA 200-301 Network Engineering Tools

- **`net_probe.py`**: Automated CCNA reachability diagnostic verifying Layer 2/3 Default Gateway routing, Layer 3 ISP Backbone connectivity, and Layer 7 DNS resolution.
- **`subnet_calc.py`**: High-performance CCNA IPv4 subnet calculator computing Network ID, Broadcast ID, CIDR masks, total addresses, and usable host ranges in O(1) time complexity.
- **`subnet_drill.py`**: Interactive terminal speed drill generating random Class C variable-length subnets to train mental Network ID calculations.
- **`port_scanner.py`**: Native Layer 4 TCP socket scanner probing standard CCNA service ports (DNS, HTTP, HTTPS, SSH) via 3-way handshake.
- **`dns_tool.py`**: Layer 7 Forward & Reverse DNS Resolver utilizing native socket libraries.
- **`binary_calc.py`**: IPv4 Decimal-to-Binary Bitwise Engine for routing logic visualization.
- **`cisco_vlan_builder.py`**: Cisco IOS automation script generating production-grade VLAN and access-port configuration blocks.
- **`mac_formatter.py`**: Layer 2 hardware address parser converting raw MAC inputs into standard Linux, Windows, and Cisco IOS formats.
- **`hash_maker.py`**: Cryptographic generator demonstrating Cisco Type 5 (MD5) and Type 8 (SHA-256) password hashing algorithms.
- **`ospf_cost.py`**: OSPF routing metric calculator demonstrating the reference bandwidth trap on Gigabit vs FastEthernet links.
- **`wildcard_calc.py`**: CCNA Cisco Wildcard Mask Inverter converting subnet masks to exact OSPF and ACL security syntax.
- **`ipv6_tool.py`**: RFC 5952 IPv6 compression and expansion engine utilizing native ipaddress parsing.
